# 本机记录索引

本文件是本机信息的固定总入口，只提供导航。业务内容尚未填写，模板不代表任何项目已开发、发布或验收。

| 想查什么 | 从哪里进入 |
|---|---|
| 当前交付和问题 | [当前进度](工作/当前进度.md) |
| 未完成工作和待确认事项 | [工作计划](工作/工作计划.md) |
| 用户原话、会议、原始材料与专题讨论 | [资料索引](资料/资料索引.md) |
| 服务器、数据库、平台服务和开发配置 | [资源索引](资源/资源索引.md) |
| 开发、测试、发布和重要决定的过程证据 | [项目记录索引](记录/项目记录/项目记录索引.md) |
| AI接手当前任务 | [AI阅读入口](记录/AI记录/阅读入口.md) → [当前交接](记录/AI记录/会话交接/当前交接.md) |
| 早期AI摘要及原始资料缺口 | [AI交接历史索引](记录/AI记录/会话交接/历史索引.md) |
| 正式业务与系统说明 | [项目信息管理](../项目信息管理.md) |

各范围的文件清单由对应索引维护，此处不再逐篇重复。索引持续维护，不按天创建。放置、更新与收尾方法见[项目信息维护](../docs/系统/开发指南/项目信息维护.md#固定索引与目录导航)。
