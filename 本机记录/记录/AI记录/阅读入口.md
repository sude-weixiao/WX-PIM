# AI阅读入口

先遵循用户最新指示及目标项目规范。新会话或上下文压缩后先读固定[当前交接](会话交接/当前交接.md)，正在工作时只补查缺少的信息。

| 缺少什么 | 从哪里补 |
|---|---|
| 本机全部资料入口 | [本机记录索引](../../本机记录索引.md) |
| 当前目标、停点、约束和接续动作 | [当前交接](会话交接/当前交接.md) |
| 交付状态和当前问题 | [当前进度](../../工作/当前进度.md) |
| 尚未完成的事项及验收 | [工作计划](../../工作/工作计划.md) |
| 稳定背景和实现位置 | [项目上下文](项目上下文.md) |
| 用户输入和参考依据 | 按任务选择[资料索引](../../资料/资料索引.md) |
| 资源和配置的维护位置 | [资源索引](../../资源/资源索引.md) |
| 历史项目事件和验证 | [项目记录索引](../项目记录/项目记录索引.md) |
| 早期AI阶段摘要及缺失来源 | [AI交接历史索引](会话交接/历史索引.md) |

不默认通读历史，不按“最终”“已发布”或文件排序猜测现状。模板尚未初始化时依据已知用户任务和实际工作区填写，不视为空白即任务结束或必须等待。

详细分工和收尾方法见[信息维护](../../../documents/系统/开发指南/项目信息维护.md)，交接骨架见[交接模板](会话交接/交接模板.md)。
