# 当前交接填写模板

当前交接是固定续接点，不复制完整项目说明、进度台账或历史。维护规则统一见[信息维护](../../../../documents/系统/开发指南/项目信息维护.md)。根据实际任务删去不适用字段，避免空占位内容进入已填写交接。

```markdown
# 当前任务主题

- 最近核对时间、用户目标和授权范围。
- 当前状态与停点；完成时说明没有继续执行步骤。
- 必须保留的改动、约束及仍未知事项。
- 当前工作区和验证范围；详细结果引用现有记录。
- 下一项明确动作及必要前置条件。
```

交付状态引用当前进度，未完成安排引用工作计划。只有仍影响接续的未完成进程或操作才保存必要定位信息，恢复前重新核对。普通问答和重复检查不建日期快照；有留档价值的决定可使用[阶段摘要模板](../../../资源/开发环境/阶段摘要模板.md)。
