# 阶段摘要填写模板

只在关键决定或阶段成果值得追溯时使用。同日同主题优先合并，必要时按主题串联跨日事件；不是每次交接必建文件。维护规则见[信息维护](../../../docs/系统/开发指南/项目信息维护.md)。

```markdown
# 日期或主题 · 阶段摘要

- 原事件日期范围：
- 后续归整日期：仅发生整理时填写

## 关键决定和阶段结果

仅保留影响后续理解的确认与结果，区分各阶段当时状态。跨日补充按实际发生日期说明。

## 必要证据

链接同主题项目记录、重要失败与验证结果，不再复制完整实现或测试清单。

## 未完成事项及保留边界

只保留会影响后续的未解决项及原文位置；当前待办从工作计划核对。
```

摘要不覆盖用户原稿、现行规则或最新授权。原文归档时注明原路径和恢复位置，现行链接按实际去向校验。

摘要形成后更新[AI交接历史索引](../../记录/AI记录/会话交接/历史索引.md)，项目事件原记录由[项目记录索引](../../记录/项目记录/项目记录索引.md)管理。
