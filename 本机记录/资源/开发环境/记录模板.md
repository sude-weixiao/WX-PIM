# 项目记录填写模板

按实际事件创建日期目录，同日同主题集中补充新增有效信息，不复制多个待发布版本。完整规则见[信息维护](../../../documents/系统/开发指南/项目信息维护.md)，示意目录见[项目记录](../../记录/项目记录/YYYY-MM-DD/)。

```markdown
# 记录主题

- 原事件日期及涉及环境：
- 本次范围、依据和授权：

## 关键决定与实际结果

区分用户确认、已知事实、采取的动作及仍未知事项；不复制整段对话。

## 验证、重要失败与证据

实际执行、结果、失败原因或未确认影响；详细报告和原始输出只在附件保存一次。

## 交付和后续

开发、提交、合并、部署、业务验收分别说明。未完成事项更新工作计划，稳定结论更新对应的现行文档，此处引用维护位置。
```

不适用项删除，模板中的空白不作为已经完成的事实。原始材料保持原意，凭据和现场数据不抄入普通记录或可同步文档。

新增或移动记录时，更新固定的[项目记录索引](../../记录/项目记录/项目记录索引.md)；正文仍按事件日期保存，不为每一天另建索引。
