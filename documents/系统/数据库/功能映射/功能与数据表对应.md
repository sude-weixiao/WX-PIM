# 功能与数据表对应

回答“一个功能使用哪些表，各表参与哪一步、读写什么”。本文件统一维护功能与表的映射，功能说明引用这里，字段详情引用单表文档。

## 对应清单

| 功能 / 功能说明链接 | 业务步骤 | 库 / schema | 表名及结构链接 | 操作 | 在该步骤中的作用 | 调用链依据 | 核验状态 |
|---|---|---|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 读取 / 新增 / 更新 / 删除 | 待填写 | 接口、服务、任务及数据访问代码位置 | 待核验 |

## 填写规则

- 按“功能—步骤—表”填写；同一功能涉及多表时逐行列出，同一表供多个功能使用时分别说明。
- 写清表的具体作用，例如“读取商品资料”或“新增任务执行记录”，避免只罗列表名。
- 包括实际涉及的公共表、关联表和异步任务用表，不只记录页面直接访问的数据。
- 不凭名称推断读写关系，检查真实调用链；未核验的映射明确标记。
- 不直接使用数据库的功能可注明“不涉及数据库”；通过外部 API 访问且无法核验的存储注明“外部服务内部表未知”。
- 文件较大时按业务模块拆分，并将本文件改为索引；拆分后不保留重复映射正文。
